# SprintZ releases

Installers and in-app updates for **SprintZ**, the printer agent for Sprint POS.

Download the latest version from **[Releases](https://github.com/hubviek/sprintz-releases/releases/latest)**:

| Computer | File |
|---|---|
| Mac with Apple Silicon (M1 or newer) | `SprintZ-<version>-macos-arm64.dmg` |
| Windows 10/11, 64-bit | `SprintZ-<version>-windows-x64.zip` |
| Windows 10, 32-bit | `SprintZ-<version>-windows-x86.zip` |

From SprintZ 1.2.2 on, installed copies update themselves from this page:
**Settings → Check for updates**.

This repository holds release files only. It contains no source code.
